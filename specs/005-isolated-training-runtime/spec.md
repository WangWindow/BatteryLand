# Feature Specification: 独立训练环境与组件查询优化

**Feature Branch**: `005-isolated-training-runtime`
**Created**: 2026-10-24
**Status**: Implemented
**Input**: 后端与训练拆成两个Python环境，减轻后端依赖压力，保持本地子进程对接，优化可避免的重复查询。

## User Scenarios & Testing

### User Story 1 - 轻量后端独立运行 (Priority: P1)

开发者安装后端后即可管理资源与实验，不必安装训练框架的全部依赖。

**Independent Test**: 在没有训练库的后端环境中启动API，操作资源并静态预览、上传组件。

**Acceptance Scenarios**:

1. **Given** 仅安装后端依赖，**When** 启动服务、查询资源和组件，**Then** 请求成功且API不导入训练库。
2. **Given** 训练环境缺失，**When** 执行动态参数检查或校验训练，**Then** 返回明确的训练环境不可用错误，基础API继续工作。

### User Story 2 - 独立环境完成训练 (Priority: P1)

开发者明确选择训练环境；配置检查、准备和执行都使用同一训练环境，后端仍管理状态、停止及结果。

**Independent Test**: 后端和训练环境不同，执行MyTask、真实电池训练及停止恢复流程。

**Acceptance Scenarios**:

1. **Given** 两个环境，**When** 执行任务，**Then** 控制桥接与训练进程使用指定训练解释器，记录实际运行身份。
2. **Given** 工作进程身份错误或准备后切换解释器，**When** 继续执行，**Then** 拒绝执行并报告失败或待核实状态。
3. **Given** 后端重启，**When** 恢复并停止原训练，**Then** 仍识别和停止原有进程组，日志与产物可查询。

### User Story 3 - 重复预览不重复解析源码 (Priority: P2)

用户多次打开组件列表、切换注册域时，复用已解析的静态组件信息。

**Independent Test**: 观察重复请求的子进程次数及耗时，并修改、添加、删除上传源码验证结果立即更新。

**Acceptance Scenarios**:

1. **Given** 源码未变，**When** 重复查询或并发查询，**Then** 静态解析结果可复用，返回对象修改不污染后续结果。
2. **Given** 上传成功或源码内容变化，**When** 再次查询，**Then** 返回最新声明和源码摘要；失败不缓存为成功。

### Edge Cases

- 解释器入口为虚拟环境符号链接，路径包含空格，或环境变量使用相对路径。
- 训练解释器不存在、不可执行、返回无效响应或身份不一致。
- 准备成功后解释器配置发生变化。
- 源码被原地编辑、替换、添加或删除；并发首次查询；返回结果被调用方修改。
- 未配置训练环境时，只安装后端仍能进行组件静态管理。

## Requirements

### Functional Requirements

- **FR-001**: 后端默认安装必须排除训练库；训练依赖在主项目单独声明，两个安装入口可重复执行。
- **FR-002**: 必须允许配置训练解释器，默认指向独立训练环境；禁止静默退回后端解释器。
- **FR-003**: 静态组件查询与上传必须独立于训练环境；动态描述、训练校验、准备和执行使用训练解释器。
- **FR-004**: 必须核对控制响应和准备回执的运行身份，保留虚拟环境入口；运行身份变更不得静默继续。
- **FR-005**: 训练环境不可用必须形成明确错误；基础API、已有训练进程的观察和终止继续可用。
- **FR-006**: 队列、串行调度、停止、重启恢复和结果采集行为保持既有契约。
- **FR-007**: 静态组件缓存必须随源码内容变化失效，隔离调用方修改，并发请求不重复解析；不得缓存训练校验和执行结果。
- **FR-008**: 不修改专业模块源码，不增加常驻训练服务、消息队列或网络通信。

### Key Entities

- **训练运行身份**：解释器入口、环境前缀、Python版本，用于校验和执行追溯。
- **静态组件快照**：源码内容指纹与解析后的组件定义，仅作为可重建的进程内缓存。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 后端独立安装、资源API及静态组件操作全部通过，后端环境不存在训练库。
- **SC-002**: 独立环境完成真实MyTask、电池CPU训练，已有停止和恢复验收通过；有可用GPU时验证显式GPU训练。
- **SC-003**: 源码未变时连续三次列表查询只解析一次；源码变化后的首次查询即反映变化。
- **SC-004**: 对相同组件集合进行前后对比，记录重复查询耗时和环境体积，不声称未测量的API内存收益。

## Assumptions

- 同机Linux部署；仍使用当前受支持Python版本和专业模块固定提交。
- 两个环境的依赖由同一主项目管理；本轮不引入相互冲突的依赖版本或独立发布周期。
- 旧共享环境设计由本规格覆盖；不改变HTTP接口和前端行为。
