# Feature Specification: 工作台导航与设置菜单

**Feature Branch**: `008-workbench-shell`  
**Created**: 2026-10-24  
**Status**: Implemented

改进工作台侧栏的信息层级和设置入口，并修复调度队列刷新时内容闪烁的问题。

## User Stories

### US1 — 稳定查看调度队列 (P1)

用户停留在调度队列时，后台自动刷新状态，但当前列表保持可见；请求较慢时不会被定时刷新反复取消。

**独立验收**：让一次队列查询保持挂起，跨过一个轮询周期后，旧数据仍显示，原请求未被轮询取消；完成后再发起下一次查询。

### US2 — 从底部设置菜单切换偏好 (P1)

用户从侧栏底部或窄屏顶栏打开设置菜单，在语言与主题子菜单中切换语言、浅色/深色/跟随系统主题。

**验收场景**：菜单可由键盘访问；两种语言均有完整文案；刷新页面后保留设置；跟随系统时响应系统主题变化。

### US3 — 使用紧凑、分组导航 (P2)

用户可以展开或折叠侧栏导航分组以聚焦某类工作；侧栏顶部只保留品牌标记和同一行的宽度控制，底部保留设置入口。

**验收场景**：折叠侧栏仍可访问全部路由；分组状态语义可读；移动端现有横向导航保持可用。

## Requirements

- **FR-001**: 轮询必须串行执行，慢请求不得被轮询周期取消，也不得相互覆盖。
- **FR-002**: 自动轮询和手动刷新期间保留最近一次成功数据；首次加载仍显示加载占位。
- **FR-003**: 设置菜单包含简体中文/英文及浅色/深色/跟随系统三种主题选择，并保存在浏览器本地。
- **FR-004**: 深色主题必须使用语义变量；次级文字颜色应更易辨认，页面不依赖轻细字体表达层级。
- **FR-005**: 侧栏标题文字移除；品牌标记与展开/折叠控件在侧栏顶部同行；设置按钮固定在侧栏底部。
- **FR-006**: 导航分组可通过鼠标和键盘展开/折叠；折叠侧栏和移动端保持全部导航入口可用。
- **FR-007**: 可见文案与无障碍名称同时维护简体中文和英文。

## Assumptions

- 主题偏好只控制浏览器界面，不写入实验配置或后端。
- 继续使用现有 shadcn DropdownMenu、Tailwind 语义色和 i18next；不引入新的设置、主题或导航依赖。
- 移动端仍使用横向路由导航；设置菜单放在顶栏并替代单独的语言控件。

## Success Criteria

- 慢轮询期间没有列表被空态或加载态替换，且并发请求数不超过 1。
- 用户从菜单完成语言和主题切换；选择在重载后保持。
- 侧栏顶部控件不换行，导航分组可键盘操作，移动端所有原有路由仍可到达。
