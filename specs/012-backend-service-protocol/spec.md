# 后端服务拆分与完整实验数据流

本规格是当前后端实现依据。与 `specs/001`–`specs/011` 冲突的旧接口和工作流不保留兼容层，
按本规格直接迁移。

## 范围和所有权

本阶段先稳定后端 HTTP 契约和消费者数据流，再开发前端。单个 FastAPI 后端提供公开 API、
SQLite 存取与内部 FIFO 调度；调度模块监测 CPU、内存、GPU 并通过应用服务认领及更新实验。
DeepPlatform 适配器负责校验、准备、启动、状态、停止和输出提取；实际训练由隔离解释器的
子进程执行，不额外暴露 HTTP 端口。

用户侧构建或上传完整 YAML 配置及完整划分 JSON，先向后端的训练校验 API 校验，再将原文、
解析结果、哈希和可信校验收据提交数据后端。数据后端只保存通过校验的版本，不拼装配置、
不自行执行数据划分算法。原始输入与运行时设备解析结果分别保存；实验列表和详情只展示
具有校验输入记录的实验。

每个实验 ID 在整个生命周期只对应一次训练。首次排队冻结输入；再次训练同一配置须
创建新实验 ID 和新运行目录。停止、失败和完成状态不得重新入队。重复 HTTP 请求只能
返回此前收据。进程身份无法确认时进入 `needs_reconciliation`，不得自动再次启动。
不提供断点续训。首版调度全局 FIFO 串行。仅支持 GPU：`auto` 在派发前解析成具体
`cuda:N`，显式 `cuda:N` 必须保留，无可用 GPU 时任务留在队列并报告原因。

固定数据根目录在启动时建立 SQLite 文件目录索引，支持分页、筛选、集合成员查询。
命名划分文件作为选择捷径；最终划分 JSON 来自客户端并经提供者校验，数据库保存其
原文、按版本和分区查询的成员索引及各分区数量摘要。科学特征统计由后续数据分析规格定义。
真实文件不上传也不复制。结果、指标、日志和产物以实验 ID
关联，并可经公开 API 查询。大文件存文件系统，数据库保存元数据与校验哈希。

数据差异分析可以直接引用固定数据源、DeepPlatform 命名集合，或已保存划分的一个或多个
分区。命名集合中无法解析到唯一现有电池的成员会从统计中排除，并在响应警告中报告数量。

BatteryLife 自定义划分由训练适配器消费。调用方提交完整划分 JSON；后端校验文件名与固定数据源的对应关系，按实验
生成只读 split 文件并仅在执行配置中注入其路径。划分不要求与提供者的内置 JSON 相同。重复 basename 在训练输入中
按一个逻辑电池处理，并选择排序稳定的相对路径。

## 验收条件

1. 启动脚本只启动后端和前端；浏览器只访问后端端口，训练子进程保留独立解释器。
2. 原文哈希、提供者提交和组件版本纳入校验收据；过期、篡改、未校验内容拒绝保存。
3. 本地调度器认领任务时最多一个任务占用串行容量；状态事件重复处理不会二次启动。
4. 资源快照有采样时间和缺失原因；`auto` 只解析到实际可用 GPU，显式卡不重映射。
5. 停止命令、终态上报、指标与产物重传具有确定语义，实验 ID 可追踪完整数据。
6. 独立 HTTP 客户端完成校验、保存、排队、停止/完成及结果查询；内部调度完成认领和运行。
7. 至少三次独立清空业务库后的完整流回归通过，随后才进入前端实现。

## Deeplatform 运行边界

BatteryLand 维护 `BatteryLandBatteryLifeDatasetFactory` 适配器，不修改子模块源码。训练仍使用固定版本的
DeepPlatform `core` 与最小 runner；默认组件及必要数据标签首次初始化时复制到项目数据目录，后续启动不覆盖。
训练只依赖 DeepPlatform `core` 和 BatteryLand 自有运行适配器；用户提供的划分 JSON 经校验后
逐实验写入只读输入目录，不要求与 DeepPlatform 内置划分一致。其他默认组件或数据标签仅在
本地初始化时复制到项目数据目录。独立评估和迁移任务不在本阶段支持。
